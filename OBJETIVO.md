Y todavía faltan dominios que normalmente no aparecen hasta que uno intenta construir el sistema de verdad: fraude, regulación, propiedad intelectual, autenticidad, conflictos entre proveedores, cambios de stock, manipulación de rankings, datos falsos, productos que se vuelven virales y desaparecen, dependencia de un proveedor, concentración de demanda, efectos de red, canibalización entre productos, elasticidad cruzada, experimentos de precio, comportamiento por país, comportamiento por dispositivo, estacionalidad, etc.

Así que yo no cerraría todavía esta lista.

El siguiente paso correcto es hacer una “interrogante exhaustiva”, no una lista de variables. Es decir: recorrer el problema desde plataforma → mercado → cliente → competencia → producto → proveedor → precio → logística → confianza → conversión → retención → riesgo → crecimiento → evolución, y en cada dominio preguntarnos:

> “¿Qué tendría que saber un estratega excepcional para poder tomar una decisión correcta aquí?”



Después de esa segunda pasada, eliminamos duplicados, agrupamos interrogantes que realmente representan la misma cuestión y buscamos huecos: preguntas que todavía no hemos formulado.

Hasta que ese inventario esté completo, no convertimos nada en variables. Ese orden es el adecuado.

Tenemos que distinguir:


PRODUCTO POPULAR
       ≠
PRODUCTO RENTABLE
       ≠
PRODUCTO CON OPORTUNIDAD
       ≠
PRODUCTO ADECUADO PARA UNA PLATAFORMA NUEVA




Una plataforma nueva debería buscar la intersección:

                  DEMANDA
                     │
                     │
              ┌──────┴──────┐
              │              │
              │ OPORTUNIDAD  │
              │              │
              └──────┬───────┘
                     │
          ┌──────────┼──────────┐
          ↓          ↓          ↓
      margen      baja       diferenciación
                  competencia
                     │
                     ↓
               producto viable




Por ejemplo, un producto puede vender muchísimo y ser una pésima oportunidad porque:

demanda       = altísima
competencia   = altísima
margen        = 4%
diferenciación= prácticamente cero



Mientras que otro:

demanda       = alta
competencia   = moderada
margen        = 35%
diferenciación= posible


puede ser estratégicamente superior aunque venda menos unidades.
